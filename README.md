# CLAIM

## DESCRIÇÂO : O Claim foi um projeto escolar desenvolvido como um primeiro contato com HTML e CSS. O projeto consistia na criação de uma marca fictícia voltada à produção de embalagens sustentáveis.

Seu principal objetivo foi praticar a estruturação de páginas web e a estilização de elementos utilizando essas tecnologias.

## TECNOLOGIAS USADAS : 
* **HTML5** - Estruturação das páginas e conteúdos.
* **CSS3** - Estilização da página.
